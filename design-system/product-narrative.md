# Product narrative

The story the site tells, for reuse in decks, posts, and demo scripts.

## One-liner

caden is a founder autopilot for investor updates and build-in-public content, grounded in what you actually shipped. (Working name, trivial to rename.)

## The loop

Connect your GitHub (Linear, Notion and other work apps too) → the agent pulls your real merged PRs, commits, releases, closed tickets and shipped docs → a team of specialist agents (summarizer → metrics → voice-matched writers) turns them into the founder comms you are supposed to publish but never do.

## The three artifacts

1. **Investor update. The hero wedge.** Founders dread the monthly update, and late updates hurt fundraises. "Never write one again" is a sentence founders pay for.
2. **Build-in-public posts** (LinkedIn + X), grounded in real diffs, not vibes.
3. **Changelog / release notes**, written the moment a release ships.

## The agent team

- Summarizer: maps every merged PR, closed ticket, shipped doc in the date range.
- Metrics agent: folds in the numbers only the founder knows (growth, burn, runway).
- Voice-matched writers: draft in the founder's own tone.
- Supporting cast used in testimonials: Compiler, Scheduler, Ghostwriter, Changelog, Runner.

## Numbers used on the site

- 60 seconds from repo to a finished draft
- 3 artifacts from every sprint (update, posts, changelog)
- 12 investor updates a year, sent on time

## Positioning lines that tested well

- "Ship the work. Send the update."
- "Never write an investor update again."
- "Pull the diffs. Write the story. Send it monthly."
- "The comms you owe, drafted from the work you shipped."
- "0 blank pages. Every sentence traces back to a real diff."

## Scope honesty (36h hackathon cut)

Shipped scope is: paste a public repo + date range + paste-your-metrics box → generate the three artifacts. OAuth, private repos, Linear/Notion sync, scheduling, and voice training are named on the page as "coming next", never implied as live.

## Demo script (60 seconds)

Paste repo → agents run → finished investor update on screen → "want it every month?" That is the whole pitch; the landing page mirrors it section by section.
